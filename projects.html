QuantRisk Analytics

Takes a set of assets and weights, builds the portfolio under an explicit rebalancing rule (five to choose from) and measures its performance and risk against a benchmark. Every number comes from a small, unit-tested function, and an interactive Streamlit dashboard displays the results.

  • Python
  • pandas
  • NumPy
  • Streamlit
  • pytest
  • GitHub Actions
  • VaRHistorical VaR and Expected Shortfall, with an out-of-sample Kupiec backtest
  • MDDDrawdowns, Sharpe, tracking error, information ratio, beta and Euler risk contributions
  • 163Unit tests against hand-calculated values, run in CI on every push

Machine learning · Fraud

Financial Fraud Detection

A two-person MSc project on 6.36M synthetic payment transactions from Kaggle. Fraud appears only in transfers (0.77%) and cash-outs (0.18%), a dependence confirmed by a chi-square test. On the fraudulent transactions, a Random Forest separates the two types with 99.2% accuracy, against 98.2% for logistic regression.

  • Python
  • pandas
  • scikit-learn
  • SciPy
